# Source snapshot

This is the full Mildly Feral application, notebook/backup/ABV logic, Worker/database source, migrations, build configuration, tests and vendor notices. Hosted project identity, hosting records, internal notes, original history, private notebooks/photos and runtime artwork are excluded. ASSET-REQUIREMENTS.json lists the omitted runtime files without private storage locations. The approved repository banner and button are included.

Supply the runtime artwork before starting the interface. The default build stores notebooks and photos in the visitor's browser using IndexedDB. No hosted credentials or notebook-storage bindings are provided, and no deployment is part of these instructions. Existing copyright and dependency-license boundaries remain.

The included `.openai/hosting.json` and legacy server source retain only generic local binding names, `DB` and `BUCKET`. They are outside the default browser build. They contain no hosted project ID or account identity. The new assets-only Worker configuration names the public app domain but declares no database, bucket, or identity bindings.

The two-edition layout includes redistributable Barlow fonts with their OFL notices. Runtime illustration exclusions also cover the Kombucha edition scene; it remains listed by path, size and hash in ASSET-REQUIREMENTS.json. The repository banner and button are carried forward from the maintained repository without further edits.
